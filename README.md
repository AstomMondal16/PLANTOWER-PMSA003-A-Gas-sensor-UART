# PLANTOWER-PMSA003-A-Gas-sensor-UART
The PLANTOWER PMSA003-A is a digital particle sensor that measures air particle concentration with high accuracy. It outputs real-time data via UART and is ideal for air quality monitoring and environmental devices.
